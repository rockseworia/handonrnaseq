# 1. Quality control

This chapter uses [fastp](https://github.com/OpenGene/fastp) to clean paired-end FASTQ files and produce an HTML and JSON report for each sample.

## 1.1 Install fastp

```bash
conda create -n fastp -c conda-forge -c bioconda fastp
conda activate fastp
fastp --version
```

Record the reported version in your analysis log.

## 1.2 Prepare the sample list

Create a plain-text file with one sample ID per line, without read suffixes:

```text
sample01
sample02
sample03
```

The script expects input files named `sample01_1.fq.gz` and `sample01_2.fq.gz`. Avoid generating the list from an unfiltered `ls` command because unrelated files and suffixes can be included accidentally.

## 1.3 Run fastp

Save this as `fastp.sh`, then replace the paths and thread count:

```bash
#!/usr/bin/env bash
set -euo pipefail

sample_file="/path/to/sample.name"
data_dir="/path/to/raw_data"
output_dir="/path/to/clean_data"
threads=12

mkdir -p "$output_dir"

while IFS= read -r sample || [[ -n "$sample" ]]; do
    [[ -z "$sample" ]] && continue

    fastp \
        --in1 "${data_dir}/${sample}_1.fq.gz" \
        --in2 "${data_dir}/${sample}_2.fq.gz" \
        --out1 "${output_dir}/${sample}_1.fastq.gz" \
        --out2 "${output_dir}/${sample}_2.fastq.gz" \
        --json "${output_dir}/${sample}.fastp.json" \
        --html "${output_dir}/${sample}.fastp.html" \
        --thread "$threads"
done < "$sample_file"
```

Run it with:

```bash
conda activate fastp
bash fastp.sh
```

fastp does not overwrite existing output/report files by default. Move or remove stale outputs before rerunning a sample.

## 1.4 Check the results

For every sample, confirm that:

- both cleaned FASTQ files exist and are non-empty;
- the HTML report opens successfully;
- read counts for R1 and R2 are consistent;
- adapter content and low-quality bases decrease as expected;
- the command completed without warnings or truncated input.

For multi-sample projects, consider aggregating reports with MultiQC; this is listed in [the roadmap](../ROADMAP.md).
